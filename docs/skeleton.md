# Skeleton

Это минимально возможная структура проекта, для того чтобы создавать ваше приложение.  
По умолчанию она оптимизированная для разработки, но имеет встроенную продуктовую сборку!!!

## Преимущества

1. Минимальный набор зависимостей.
1. Не навязывает структуру проекта.
2. Не навязывает способ работы с БД.
3. DOCKER READY:
    1. Вывод сообщений в stdout
    2. Есть dev окружение в docker compose для разработки.
        1. Детальный вывод логов в сообщениях.
        2. Легкий способ расширения нужными сервисами(S3, elasticsearch, clickhouse, очереди и тд).
    3. Есть сбора оптимизированная для прода
        1. Логирование в сообщений в JSON формате.
        2. Убираются dev зависимости (xdebug, composer, composer --no-dev и тд).
        3. Готов к интеграции в ваш ci/cd инструмент сборка image, с возможностью расширения проверок.
4. Отсутствие legacy и обременения обратной совместимостью.
