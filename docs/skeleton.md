# Skeleton

Это минимально возможная структура проекта, для того чтобы создавать ваше приложение.  
По умолчанию она оптимизированная для разработки, но имеет встроенную продуктовую сборку!!!

## Преимущества

1. Минимальный набор зависимостей.
1. Не навязывает структуру проекта.
2. Не навязывает способ работы с БД.
3. DOCKER READY:
    1. Вывод сообщений в stdout
    2. Есть dev окружение в docker compose для разработки.
        1. Детальный вывод логов в сообщениях.
        2. Легкий способ расширения нужными сервисами(S3, elasticsearch, clickhouse, очереди и тд).
    3. Есть сбора оптимизированная для прода
        1. Логирование в сообщений в JSON формате.
        2. Убираются dev зависимости (xdebug, composer, composer --no-dev и тд).
        3. Готов к интеграции в ваш ci/cd инструмент сборка image, с возможностью расширения проверок.
4. Отсутствие legacy и обременения обратной совместимостью.

с минимальными требованиями:

1. git - чтобы склонировать проекта
2. docker - чтобы поднять dev окружение.
3. make - для простоты запуска команд, можно запускать команды в консоли длинной версией.

Как развернуть проект

```
git clone https://github.com/cekta/skeleton <project>
cd <project>
make dev
```

DEV версия проекта откроется на [http://localhost:8080](http://localhost:8080)

Внутри проекта всего 4 PHP файла, 2 из которых это демонстрация для HTTP обработчика и CLI команды.

Для сборки prod версии:

```
make image
```

Соберет продуктовую версию проекта, которую можно задеплоить на любую машину с docker, в k8n, в bare metal и тд.   
В зависимости от ваших предпочтений и убеждения.

Чтобы запустить продуктовую версию (после build)

```
docker run -p 8090:8080 --rm cekta-app:latest
```

Продуктовая версия будет на [http://localhost:8090](http://localhost:8090) естественно вы можете тэги и параметры
переназвать.
